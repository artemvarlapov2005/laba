# Единый шаблон лабораторной работы МИЭТ

Один проект для новых лабораторных: `main.tex` — реквизиты и содержание,
`mietlab.cls` — страница и титульник, `lab-components.tex` — шрифты,
заголовки, таблицы, рисунки и код. Разных профилей оформления нет.

## Начать новую лабораторную

1. Скопируйте папку проекта.
2. В `main.tex` измените `\LabSetup{...}`: номер, тему, ФИО, группу, дисциплину,
   город и год. Кавычки темы входят в значение `title`.
3. Замените примеры содержанием новой работы. Удалите ненужные разделы.
4. Добавьте свои изображения в `assets/` и замените пути в `\LabFigure`.
5. Соберите **XeLaTeX**. Для номеров рисунков и ссылок нужно два прохода.

Если в исходном отчёте указан вариант, добавьте `variant={Вариант 3}` в
`\LabSetup`: строка появится под темой. Ключ `studentline` позволяет сохранить
точную формулировку, например `studentline={студент группы П-42}`.

```bash
latexmk main.tex
```

Без latexmk:

```bash
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
```

Нужен TeX Live или MiKTeX с пакетами из класса. Для русских переносов
в TeX Live должен быть установлен `texlive-lang-cyrillic`.

## Times New Roman

Подстановка похожего шрифта отключена. Если Times New Roman отсутствует,
сборка выдаёт ошибку. В проверенном `main.pdf` встроен именно Times New Roman.

Можно использовать установленный системный Times New Roman либо создать
папку `fonts/` рядом с `main.tex` и положить туда четыре имеющихся у вас файла:

```text
fonts/times.ttf     — обычный
fonts/timesbd.ttf   — полужирный
fonts/timesi.ttf    — курсив
fonts/timesbi.ttf   — полужирный курсив
```

В Windows они обычно находятся в `C:\Windows\Fonts`. Шрифты в архив проекта
не включены. Для Overleaf загрузите проект и эти четыре файла, затем в настройках
компилятора выберите **XeLaTeX**; главным документом должен быть `main.tex`.

## Согласованное оформление

| Элемент | Настройка |
| --- | --- |
| Лист | А4, 210 × 297 мм |
| Поля основной части | слева 30 мм, справа 15 мм, сверху и снизу 20 мм |
| Шрифт | Times New Roman во всех текстовых элементах, включая код |
| Кегль | 13 пунктов Word/PDF: `13bp` в TeX |
| Межстрочный интервал | 1,5: базовые линии через `19.5bp` |
| Абзацы | по ширине, без красной строки и добавочного интервала |
| Заголовки | слева, полужирные, 13 пунктов, без автоматического увеличения |
| Страницы | номер снизу по центру листа; на титульнике скрыт, далее 2, 3, … |
| Таблицы | чёрная полная сетка 0,5 пункта, без заливки; поля по бокам 5 пунктов |
| Заголовки таблиц | полужирные, 13 пунктов; содержимое выровнено сверху |
| Текст в таблицах | Times New Roman 13 пунктов, интервал 1,5, по ширине; перенос только между словами |
| Рисунки | по центру, без рамки; пропорции изображения сохраняются; перед картинкой одна пустая строка (19,5 пункта) |
| Подписи рисунков | снизу, по центру, «Рисунок N — Название», обычный шрифт 13 пунктов; после подписи одна пустая строка (19,5 пункта) |
| Код | отдельный серый блок RGB 245/245/245 с внутренними полями 4 мм со всех сторон и внешними отступами минимум 19,5 пункта сверху/снизу; Times New Roman 13 пунктов, интервал 1,5 |

Поля взяты из ГОСТ 7.32–2017, раздел 6.1; правило нумерации — из раздела 6.3.
Это шаблон **по пользовательским образцам и согласованным требованиям**.
Отступ абзаца оставлен нулевым по вашему выбору; формат титульника и заголовков
сохранён по образцам. Полная структура научного отчёта по ГОСТ здесь не добавляется.

В TeX `pt` равен 1/72,27 дюйма, а пункт Word/PDF — 1/72 дюйма (`bp`).
Поэтому здесь используется `13bp`: в самом PDF проверяется размер ровно 13,0.
Обычные команды размера (`\small`, `\footnotesize`, `\Large` и т. п.)
также оставлены на 13 пунктах.

## Титульник

Положение реквизитов измерено в первом PDF «ЛР1_Варлапов_Артем_Рамблер (4).pdf».
Строки стоят на измеренных базовых линиях, независимо от заполнения основной части.
Блок «Выполнил» прижат вправо. ФИО в исходнике было вписано отдельно и немного
правее этого блока — его правый край сохранён.

Расстояния между отдельными реквизитами титульника — самостоятельные отступы.
Если тема или другой реквизит переносится внутри своего блока, интервал между
его строками остаётся 1,5. Тема может занимать две-три строки без сдвига блока автора.

В первом PDF кегль титульника записан как 12,96, а ФИО набрано Liberation Serif.
В шаблоне всё приведено к Times New Roman 13,0 по вашему указанию. Поэтому
очертания ФИО отличаются от исходника; это ожидаемое изменение шрифта.
Точные результаты сверки находятся в `verification/layout-report.md`.

## Команды для содержания

```latex
\LabHeading{Выполнение работы}       % отдельный полужирный заголовок
\LabLabel{Цель работы}{Текст цели.}   % полужирная метка и обычный текст
\LabNewPage                         % начать страницу вручную
```

### Таблицы

`L{...}` — ширина столбца с боковыми полями и линией сетки.
`C{...}` — такой же столбец с горизонтальным выравниванием по центру.
Сумма ширин столбцов и одной крайней линии должна равняться `\linewidth`.
Для последнего столбца в примерах эта линия вычитается явно.

```latex
\begin{labtable}{|L{0.4\linewidth}|L{\dimexpr0.6\linewidth-\arrayrulewidth\relax}|}
\hline
\LabTableHead{Действие} & \LabTableHead{Результат} \\\hline
\endfirsthead
\hline
\LabTableHead{Действие} & \LabTableHead{Результат} \\\hline
\endhead
Первое действие & Ожидаемый результат. \\\hline
Второе действие & Другая проверка. \\\hline
\end{labtable}
```

Таблица переносится между строками на следующие страницы, заголовок повторяется.
Для нескольких абзацев в ячейке используйте `\par`, как в `main.tex`.
Переносы слов по слогам в ячейках отключены: например, «Страница результатов»
переносится между словами, а «результатов» остаётся целым. Если целое слово
шире столбца, увеличьте его ширину.
Не уменьшайте текст таблицы через `\resizebox` или `\scalebox`: это меняет кегль.
Названия таблиц по умолчанию не добавлены — в первой лабораторной их нет.

### Рисунки

```latex
\LabFigure{assets/result.png}{Результат выполнения тестов}{fig:result}
Результат показан на рисунке~\ref{fig:result}.

% Необязательный аргумент — ширина:
\LabFigure[0.8\linewidth]{assets/result.png}{Результат}{fig:other}
```

Подпись и изображение держатся вместе. По умолчанию ширина — 94 % текстового поля,
как во втором образце. Текст внутри скриншота сохраняется в исходном виде,
как вы подтвердили. Включённый скриншот — пример из второго предоставленного PDF.
Перед изображением и после подписи добавлено по 19,5 пункта — одна пустая строка
с интервалом 1,5. Общая настройка — `\LabFigureOuterSkip` в `lab-components.tex`.

### Код

```latex
\begin{labcode}[language=Java]
public class Example {
    // Ваш код
}
\end{labcode}
```

Из файла: `\LabCodeFile[language=Java]{src/Example.java}`.
`labcode` и `\LabCodeFile` используют один объект оформления: серый фон без рамки,
внутренние поля 4 мм слева, справа, сверху и снизу. Общая настройка полей —
`\LabCodePadding` в `lab-components.tex`. Длинный блок может продолжаться
на следующей странице, сохраняя оформление.
Перед блоком и после него задан минимальный внешний отступ 19,5 пункта — одна
пустая строка с интервалом 1,5. Он сохраняется и сразу после заголовка. Общая
настройка — `\LabCodeOuterSkip`; метрики соседней строки учитываются дополнительно.
Длинные строки автоматически переносятся. Times New Roman — пропорциональный шрифт,
поэтому табличное выравнивание комментариев пробелами может отличаться от IDE.
В образце второй лабы код был Liberation Mono 8,5; здесь он намеренно приведён
к вашему требованию Times New Roman 13 с интервалом 1,5.

## Проверка собственного PDF

```bash
python -m pip install pymupdf
python verification/check_pdf.py main.pdf
```

Проверка читает встроенные шрифты и кегль всех текстовых объектов PDF.
Результат сохраняется в `verification/main-audit.json`.
Проверка не анализирует шрифт внутри растровых скриншотов.
