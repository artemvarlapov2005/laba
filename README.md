## Оформление

А4, поля 30/15/20/20 мм, Times New Roman 13 пунктов во всех текстовых
элементах, межстрочный интервал 1,5, абзацы без красной строки.
Титульник оформлен по первому образцу; номер страницы снизу по центру,
на титульнике скрыт. Таблицы имеют чёрную сетку и переносы между целыми
словами. Код выделен серыми блоками с внутренними полями 4 мм и внешними
отступами минимум в одну пустую строку (19,5 пункта), как у рисунков.

Шаблон и заполненный отчёт используют одинаковые `mietlab.cls`
и `lab-components.tex`. [Архив шаблона](latex-lab-template.zip).

Для сборки нужны XeLaTeX и Times New Roman; выполните `latexmk main.tex`
из папки шаблона или отчёта. Инструкции по установке шрифтов и работе
в Overleaf — в [руководстве](latex-lab-template/README.md).
Результаты проверки шрифтов, кегля, интервалов и сохранности содержания —
в `verification/` каждого проекта.
