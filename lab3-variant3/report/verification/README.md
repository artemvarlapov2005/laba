# Результаты проверки

- Содержание PDF и DOCX совпадает при исключении пробелов и номеров страниц.
- Содержание оформленного PDF совпадает с источником при исключении пробелов, номеров страниц и типографских переносов: 11 659 символов.
- 10 Java-листингов и 2 вывода JUnit сохранены побайтно.
- В готовом PDF используются только TimesNewRomanPSMT и TimesNewRomanPS-BoldMT, кегль каждого текстового объекта 13,0.
- Проверено 217 межстрочных промежутков: 19,5 пункта (13 × 1,5).
- А4; поля 30/15/20/20 мм. Номера страниц по физическому центру листа; титульник учитывается и не имеет видимого номера.
- Текст не выходит за поля; названия классов в таблицах не разрываются.
- Код имеет внутренние поля 4 мм, исходные знаки `*` и `-` отображаются без масштабирования и замены символов. Перед и после блока предусмотрена минимум одна пустая строка (19,5 пункта), включая вставку после заголовка. Проверены все промежутки: видимое расстояние перед серым фоном около 22,2 пункта, после — около 23,3; оно учитывает метрики соседней строки. Продолжения кода на границе страниц не получают лишнюю пустую строку.
- Сборка завершена без ошибок, предупреждений о шрифтах и выходов текста за границы.
- Обе таблицы размещены целиком, без разделения строк между страницами. Раздел с двумя результатами тестирования и вывод расположен целиком на странице 15.

`main-audit.json` содержит измеренные шрифты, кегль и координаты текста. `content-audit.json` содержит итог проверки содержания и геометрии. `source-manifest.json` содержит исходные абзацы, таблицы и хеши файлов кода.
