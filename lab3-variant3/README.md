# Лабораторная работа №3 — вариант 3

Исходный класс — `TextLine` из лабораторной №2. В лабораторной №3 нет
отдельного списка вариантов: иерархия строится вокруг своего исходного класса.
Ссылка в задании на класс из лабораторной №3 интерпретирована как ссылка
на ранее выполненную лабораторную №2.

Добавлены наследники `RussianTextLine`, `EnglishTextLine` и агрегирующий
класс `TextDocument`. Наследники устанавливают язык при создании, но сохраняют
методы базового класса. Документ хранит строки и суммирует их текущие длины.

Инкрементальное тестирование сверху вниз:
1. `TextDocumentTest`: проверка верхнего класса с заглушками `TextLineStub`.
   Заглушка возвращает заданную длину, независимо от массива символов.
2. `TextDocumentIntegrationTest.documentWorksWithRealTextLines`: подключение
   настоящего `TextLine` вместо заглушек.
3. Остальные интеграционные тесты: подключение наследников и проверка
   изменения общей длины после изменения хранящейся строки.

Модульные тесты предусмотрены для всех четырёх классов программы.
Всего 27 тестов: 24 модульных и 3 интеграционных. Использован JUnit 4.13.2,
Mockito не требуется: программная заглушка написана вручную.

Запуск: JDK 8+ и Maven, команда `mvn test` из папки проекта.
В IntelliJ IDEA можно открыть `pom.xml` как Maven-проект и запустить тесты
из `src/test/java`.
